# Thread Chasers: sources

Every bead's fact card cites at least two of these (ids in `sources: [...]` in `src/cases/*.ts`;
`npm test` checks that each id exists here). Dates and places were checked with web searches in
October 2026. Primary-source excerpts are **quoted** only from public-domain texts and are otherwise
**retold** (labelled "Retold from …" in the game).

Format: `- **id**: description — URL`
